# Mallorca Likes You

Aplicación Android multiusuario para descubrir Mallorca. Consulta la carpeta `app/` para la aplicación Android y `backend/` para la API PHP y el esquema inicial de base de datos.

La compilación del APK se realiza mediante GitHub Actions. El APK actual es de depuración; la firma permanente y la distribución de producción se configurarán antes de publicar.
